## 1. Настройка окружения

Сначала создаём виртуальное окружение:

```bash
python -m venv venv
```

Если команда `python` не находится, используйте `python3`.

Активируем его.

Windows (cmd и PowerShell):

```bash
venv\Scripts\activate
```

Linux, macOS и WSL:

```bash
source venv/bin/activate
```

В начале строки терминала появится `(venv)`. Выйти из окружения на любой ОС: `deactivate`.

Теперь установим библиотеки. `openai` - клиент API, `python-dotenv` - чтение ключа из файла `.env`:

```bash
pip install openai python-dotenv
```

Создадим файл `requirements.txt` и скопируем в него список установленных библиотек:

```bash
pip freeze > requirements.txt
```

Чтобы хранить API-ключ безопасно, создаём файл `.env` в корне проекта:

```plaintext
OPENAI_API_KEY=your-api-key-here
```

**Важно!** Добавьте `.env` в `.gitignore`, чтобы не загрузить ключ в репозиторий.

### Полезные советы:

1. API-ключ берём [в личном кабинете OpenAI](https://platform.openai.com/api-keys).
2. Никому не передавайте свой ключ!

## 2. Обращение к OpenAI Responses API

Создаём файл `main.py` и пишем базовый код:

```python
from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

api_key = os.getenv("OPENAI_API_KEY")

client = OpenAI(api_key=api_key)

def get_response(text: str, client: OpenAI):
    response = client.responses.create(model="gpt-6-luna", input=text)
    return response
```

Что здесь происходит:

- **Импорты**:
  - `OpenAI` - основной класс для API.
  - `load_dotenv` - загружает переменные из `.env`.
  - `os` - для доступа к переменным окружения.
- **Настройка окружения**: Загружаем `.env` и достаём API-ключ:
  ```python
  load_dotenv()
  api_key = os.getenv("OPENAI_API_KEY")
  ```
- **Создаём клиента OpenAI**:
  ```python
  client = OpenAI(api_key=api_key)
  ```
- **Функция для запроса к API**:
  ```python
  def get_response(text: str, client: OpenAI):
      response = client.responses.create(model="gpt-6-luna", input=text)
      return response
  ```

Модель `gpt-6-luna` - текущая недорогая модель для текстовых запросов.

## 3. Главный цикл

Теперь добавляем интерактивное общение:

```python
if __name__ == "__main__":
    print("Введите ваш вопрос (или 'exit' для выхода):")
    while True:
        question = input("Вы: ")
        if question.lower() == "exit":
            print("Завершение программы.")
            break
        answer = get_response(question, client)
        print("AI:", answer.output_text)
```

Как это работает:

- Программа запустится, только если её вызвать напрямую;
- Показываем пользователю подсказку;
- Запускаем бесконечный цикл общения;
- Если введено `exit` - выходим;
- Иначе отправляем запрос в API и выводим ответ.

Запуск из корня проекта, когда окружение уже активировано:

```bash
python main.py
```

## 4. Troubleshooting

В актуальном Python SDK классы ошибок импортируются из пакета `openai`, без вложенного модуля `openai.error`.

### Ошибка авторизации

```
openai.AuthenticationError: Incorrect API key provided
```

Проверьте ключ в `.env` и то, что `load_dotenv()` вызывается до чтения переменной.

### Модуль не найден

```
ModuleNotFoundError: No module named 'openai'
```

или

```
ModuleNotFoundError: No module named 'dotenv'
```

Активируйте виртуальное окружение и установите библиотеки: `pip install openai python-dotenv`.

### Ошибка сети

```
openai.APIConnectionError

openai.APITimeoutError
```

Проверьте интернет, брандмауэр, попробуйте VPN (скорее всего проблема в отсутствии VPN :-D).

### Ошибка запроса

```
openai.BadRequestError
```

Раньше это исключение называлось `InvalidRequestError`. Проверьте:

- Название модели;
- Длину текста;
- Формат данных;
- Параметры, которые модель не принимает (см. задание про `reasoning.effort` и `temperature`).



### Превышен лимит запросов

```
openai.RateLimitError
```

Проверьте лимиты и добавьте задержку при повторных запросах.

## 5. Задание

1. Реализовать системный промпт через переменную окружения в `.env` либо через ручной ввод и выбор промпта с сохранением в базу данных, если в терминале выбрана соответствующая опция. В Responses API промпт передаётся параметром `instructions` или сообщением с ролью `developer`. Реализовать хотсвап между системными промптами.
2. Поэкспериментировать и описать в отчёте, как меняется ответ. На reasoning-моделях (`gpt-6-luna` и другие GPT-5/GPT-6) меняйте `reasoning.effort`: `none`, `low`, `medium`, `high`. У `gpt-6-luna` по умолчанию `medium`. Параметр `temperature` на них принимается только вместе с `reasoning={"effort": "none"}`; без этого API отклоняет значение, отличное от `1`. На более старых моделях без reasoning (`gpt-4o`, `gpt-4.1`) меняйте `temperature`.
3. Реализовать ведение истории диалога, чтобы модель помнила предыдущие реплики. В `input` передавайте список сообщений и ограничивайте его шестью последними: 3 от пользователя и 3 от ассистента. Также можете попробовать использовать [Conversation API](https://developers.openai.com/api/docs/guides/conversation-state?api-mode=responses#manually-manage-conversation-state).
